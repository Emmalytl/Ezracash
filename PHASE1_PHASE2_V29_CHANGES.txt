Admin finance updates
- Expense records now support an optional receipt attachment.
- Receipts can be uploaded as PDF or image files.
- Mobile users get a dedicated “Take photo” camera capture control.
- Receipt limit is 4 MB.
- Receipts are stored in a dedicated PostgreSQL expense_receipts table; existing expenses and existing database data are preserved.
- Authorized administrators, developers and staff can open attached receipts from the expense ledger.
- Receipt files are served through an authenticated route and are not public URLs.
- Staff expense entry supports the same receipt upload/camera workflow.
- Receipt presence is shown in the expense ledger.

No /admin/setup action is required. No existing database tables are reset or recreated; migrations use CREATE TABLE IF NOT EXISTS.
